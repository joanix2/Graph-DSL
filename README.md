# Graph DSL

Un langage spécifique au domaine (DSL) pour définir et simuler des graphes avec des règles d'évolution.

## Structure du projet

- `grammar/` : Grammaire du DSL
- `src/` : Code source principal
- `src/examples/` : Exemples d'utilisation du DSL

## Installation

```bash
pip install -r requirements.txt
```
